## Taller Proyecto 1


# Descripcion: 

El siguiente documento explica como replicar los pasos de experimentación
en pdf titulado: Documentación. En el anterior documento se hace referencia al actual en la seccion de metodología 


# Requerimientos: 

* Python3, version recomendada: 3.13.5 o superior 

* Matplotlib, version recomendada: 3.11.1 o superior

* Numpy, version recomendada: 2.5.2 o superior 

* Crear una carpeta llamada imagenes en el mismo repositorio en el que se guardarán los scripts 

# Instrucciones: 

1) Asegurarse de tener creada la carpeta imagenes en el mismo repositorio donde vaya a ejecutar los archivos. 

2) Asegurarse de tener los archivos Signal_Analyzer.py y Signal_Generator.py en la misma carpeta donde vaya a ejecutar los archivos. 

3) Correr el archivo prueba_parte2.py 

4) Correr el archivo prueba_parte3.py 


# Funcionamiento: 

Una vez se corran ambos archivos, el archivo 'prueba_parte2.py' generará un resumen en consola de comparación de tiempos de ejecución de DFT y FFT, y procederá a guardar en la carpeta imagenes diferentes imagenes de magnitud y fase para los distintos casos de prueba. 
Por su parte, el archivo 'prueba_parte3.py'generará un resúmen de resultados en consola, el cual contiene el resultado esperado de retardo y la comparación de tiempos entre correlación directa y via FFT, finalmente: El archivo 'imagenes_parte3.py' generará la imágen de correlación del chirp con el leakeage restado y una imágen de la correlación de una señal acústica senoidal.
